# cross-disciplinary-models（跨学科方法通论）

一个可全局复用的 AI Agent 技能（Skill）：用 **25+ 学科核心思维模型** 与 **《资本论》《矛盾论》《实践论》三大方法论**，对任意问题进行多模型交叉分析。

知识框架源自所长林超《跨学科通识课》25 讲（熵与热力学、系统论、工程学、函数、脑科学、复杂性科学、认知心理学、社会网络学、金融学、心理学、语言表达、概率统计、经济学、人类学、信息论、营销学、历史学、古代哲学、现代哲学、会计学、投资大师思维、生理学、自我管理），并按「**矛盾论定主次 → 多学科交叉透视 → 资本论析结构 → 实践论闭环验证**」组织为一套完整的分析工作流。

## 它能做什么

对任意复杂问题（职业选择、副业创业、投资决策、感情人际、学习备考、健康管理、技术方案、趋势判断）输出结构化深度分析：

1. **界定真问题**：区分症状与病根，显式列假设，扫描"错过即归零"的单点致命风险
2. **矛盾分析定主次**（矛盾论）：列全部矛盾 → 锁主要矛盾 → 判矛盾主要方面 → 预判转化信号
3. **选模型**：按问题类型路由表选 3–6 个学科；涉钱的问题必过一遍资本论
4. **多模型交叉验证**：每个模型独立给判断 → 找共识区与冲突区 → 冲突用主要矛盾裁决权重
5. **实践闭环**（实践论）：行动清单（含操作细则）+ 可证伪条件句预言（带对账时间与退出判据）

## 如何使用

本技能遵循通用的 Agent Skill 规范（`SKILL.md` + frontmatter + 渐进式参考文件），可用于任何支持该规范的智能体：

- **Kimi**：在技能管理中导入本仓库打包的 `.skill` 文件（见 Releases），或将本目录放入用户技能目录
- **Claude Code**：将本目录复制到 `~/.claude/skills/` 下即可被自动发现
- **其他智能体 / 自定义 Agent**：把 `SKILL.md` 内容注入系统提示词，分析时按需读取 `references/` 下对应文件

触发场景示例：

> "帮我深度分析要不要辞职做 XX" / "多角度分析一下这个项目值不值得投" / "用思维模型拆解我现在的处境" / "接下来半年该怎么排主次"

## 设计原则

- **结论先行，直断风格**：拒绝两头堵的模糊断语
- **可证伪**：预言写成条件句并给对账时间，正负结果都能对账
- **锤子综合征防御**：每个模型必须产出独立增量，同义即砍
- **术语白话化**：方法论概念首次出现必须给人话翻译
- **务实切割**：模型用于启发，最终落地为以现有条件为起点的行动
