> 一个 Agent 技能（Skill）：用 25+ 学科核心思维模型，加上《资本论》《矛盾论》《实践论》三大方法论，把 AI 的"分析"从正确的废话变成可验证的判断。

知识框架源自所长林超《跨学科通识课》25 讲，组织方式是：**矛盾论定主次 → 多学科交叉透视 → 资本论析结构 → 实践论闭环验证**。

---

## 为什么做这个技能

AI 做分析有四个典型的翻车模式，这个技能就是为修它们而生的。

### 翻车 #1：正确的废话

> "凡事都有两面性，要辩证看待。"

**问题**：你问"要不要辞职做副业"，AI 给你一段两头堵的废话——既说了风险也说了机会，等于什么都没说。

**修复**：技能强制**结论先行、直断风格**，输出模板第一节就是「结论直断（含置信度）」，禁止车轱辘话。

### 翻车 #2：单一视角打天下

> 拿着锤子，看什么都是钉子。

**问题**：AI 默认只用一两个学科视角，问感情谈沟通技巧，问副业谈努力坚持——视角单一，深度自然没有。

**修复**：内置 **25+ 学科、188 个思维模型**的路由表，按问题类型选 3–6 个学科交叉透视，每个模型必须产出独立增量，同义即砍。

### 翻车 #3：分不清主次

**问题**：十条建议并列扔给你，哪条是命门、哪条是噪音，自己猜。

**修复**：用《矛盾论》做结构化排序——列全部矛盾 → 锁主要矛盾 → 判矛盾主要方面 → 预判转化信号。主要矛盾一抓，其他建议自动归位。

### 翻车 #4：无法验证的预言

> "你明年财运不错。"

**问题**：说了等于没说，对了没法复现，错了没法追责。

**修复**：用《实践论》收束——每个判断改写成**条件句预言**（"若 X 在 T 时间内发生，则 Y 成立，执行 Z"），带对账时间和退出判据，正负结果都能对账。

## 五步分析工作流

```
① 界定真问题 ──→ ② 矛盾论定主次 ──→ ③ 选模型 ──→ ④ 多模型交叉 ──→ ⑤ 实践论闭环
   症状vs病根       抓主要矛盾         3-6个学科      共识与冲突        行动+条件句预言
   扫致命风险       判主要方面         涉钱必过        权重裁决          对账时间点
```

## 设计原则

- **结论先行，直断风格** —— 拒绝两头堵的模糊断语
- **可证伪** —— 预言写成条件句并给对账时间，正负结果都能对账
- **锤子综合征防御** —— 每个模型必须产出独立增量，同义即砍
- **术语白话化** —— 方法论概念首次出现必须给人话翻译
- **务实切割** —— 模型用于启发，最终落地为以现有条件为起点的行动
