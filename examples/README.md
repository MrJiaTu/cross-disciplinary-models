# 样例库 Examples

这里放**完整真实产出**：同一个问题，不加技能时 AI 会给什么，加了技能会给什么，差别在哪里。

| 样例 | 问题类型 | 主要展示 |
|---|---|---|
| [01 要不要辞职做跨境副业](01-quit-job-for-side-business.md) | 副业/创业 + 涉钱 | 资本论定段位、凸性反转决策、幸存者偏差校正先验 |
| [02 人生第一个 10 万的复利规划](02-first-100k-compound-plan.md) | 投资/资产配置 + 涉钱 | 把三个互相冲突的目标算成不可行、储蓄率 vs 收益率的 2.8 倍杠杆、净资产口径重定义目标 |

> **问题背景均为虚构示例**，不对应任何真实个人；年龄、城市层级、薪资、房贷、存款等数字是为了让分析有可算的口径而设定的。

## 怎么复现

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/MrJiaTu/cross-disciplinary-models.git ~/.claude/skills/cross-disciplinary-models
```

然后直接问样例里的问题（把背景数据换成你自己的），或粘贴：

```
用跨学科思维模型帮我深度分析：要不要辞职做 TikTok Shop 东南亚美妆？
背景：28 岁，二线城市 SaaS 客户成功，月薪到手 9.5k；房贷月供 4200，家庭月固定支出 1.1 万；
妻子月入 8k，存款 6 万；会一点短视频剪辑；同事上个月兼职出了 3000 单。
```

```
用跨学科思维模型分析：我 24 岁，工作 2 年存了 10 万，无负债，想 30 岁前结婚并有一套不负债的自住房，
手上还要有现金流。第一个 10 万怎么规划才能实现复利？
```

## 怎么测（Qoder / 其他宿主通用）

1. 先拿一个**干净的测试项目目录**（不要拿本仓库本身测，否则模型会直接读到 examples 里的答案）。
2. 安装：`node <本仓库路径>/bin/cdm.js --tool qoder --dir <测试项目目录>`（其他宿主把 `qoder` 换成 `cursor` / `claude` 等；先加 `--dry-run` 看写哪里）。
3. 用宿主**打开那个测试目录，新建一个会话**。必须新会话：在已有上下文里测，测到的是污染样本。
4. 只粘贴下面那一句提问，不加任何提示词、不提“技能”二字。
5. 拿输出比对下方「验收清单」，把原文存成 `skill-output-*.md` 或截图。

### 验收清单（逐项打勾）

- [ ] 七个章节齐全且顺序正确：结论直断 → 矛盾定位 → 多模型透视 → 交叉验证 → 行动方案 → 验证与对账 → 本分析可能错在哪
- [ ] 结论带置信度，且开头没有“既有机会也有风险”这类两头堵
- [ ] 多模型透视 3–6 条，每条标了【学科·模型】且结论不互相同义
- [ ] 引用的模型名全部能在 `references/` 里查到（**这一项最容易挂，也是最重要的**）
- [ ] 涉钱问题过了资本论（谁创造/传递/获取价值）
- [ ] 至少有两条带具体日期的对账预言，且每条有“不达标则如何归因”
- [ ] 最后一节确实列出了 2–4 条未验证前提，而不是写“以上仅供参考”
- [ ] 缺数据的地方写的是“需查证 + 查证动作”，而不是填了个看着合理的百分比

同一问题跑 3 次看结构稳定度；再换一个不同类型的问题（如“该不该接这个 offer”），看第三步路由是否真的换了学科。

**兼容兜底**：若 Qoder 没自动加载 `.qoder/rules/`，把 `prompts/cdm-lite.md` 分隔线以下整段粘在提问前面。这也是一次有效测试，但测的是 lite 版而不是完整版，记录时要分开标注。

## 基线来源（请先读这一节）

- **例 01**：真实截图。Gemini（Flash 扩展思考）与 ChatGPT（思考模式）对同一背景的完整回答，存于 [`assets/`](assets/)，未修饰。
- **例 02**：同上，也是真实截图（`baseline-chatgpt-thinking-ex02.webp`、`baseline-gemini-flash-ex02.webp`）。

截图统一存为 WebP（长截图降采样到宽 ≤ 1100、q78），四张共 812 KB；原 PNG 约 3.2 MB，未入库。新传截图请先压：`ffmpeg -i in.png -vf "scale='min(1100,iw)':-2:flags=lanczos" -c:v libwebp -quality 78 out.webp`。

两个真实基线都比任何人预期的强：它们已经会结论直断、给数字、给触发线、给行动清单，甚至会把互斥目标算成不可行（例 02 里 Gemini 直接算出"全款买房需年均净储蓄 12–25 万"而判不可行）。所以两个样例的差异表只主张四条站得住的差异：

| 差异 | 真实基线的表现 |
|---|---|
| 判据日期与退出判据 | 有触发线与动作排期（"本周完成"、"净利连续 3 个月超阈值"），但没有哪天回看、不达标如何归因、何时直接退出 |
| 成功后归因 | 两份样例都未处理"若真做成了，是能力还是补贴窗口/牛市/家庭支援" |
| 自我否定 | 无。只有系统层的"请核实信息"，没有"本分析依赖哪 4 处未验证前提" |
| 假设集中声明 | 假设存在但散落。例 01 里两个模型把同一句背景算成 3000 与 7200 的月缺口（差 2.4 倍），都没声明自己用了哪个口径 |

已经**不再成立**、也不要拿来当卖点的三条（例 02 的实测已逐条推翻）："AI 不给数字"、"AI 不做结论直断"、"AI 看不出目标互斥"。另需注意：数字自洽性不能一概而论——例 02 里 Gemini 的 ¥533,187 复算仅差 0.1%，而 ChatGPT 的"10 万 + 48 万 = 58 万"漏计了它自己主张的复利（应为 77.6 万）。

不要把本仓库读成"AI 不会分析"。它的主张窄得多也可检验得多：**强模型已经会给好答案，技能负责让这份答案能在指定日期被判对错。**
