## 模块1：熵与热力学

**一句话定位**：一切封闭系统都自发走向混乱——理解秩序为何昂贵、维持为何耗能，以及"续命"必须靠输入什么。

**核心模型**：

- **熵增定律**：孤立系统的熵（无序度）只增不减，混乱是默认状态，秩序是例外且需持续付出代价 → 分析时的提问：「这个系统是在封闭运行还是与外界交换？如果切断一切外部输入，它多久会退化到无序？」

- **耗散结构**：远离平衡态的开放系统可通过持续耗散能量与物质，自发涌现出更高层级的有序（城市、生命、企业皆然） → 分析时的提问：「这份有序靠哪几条'流'维持（能量流、物质流、信息流、人才流、资金流）？哪条流先断，系统就先垮？」

- **开放系统**：只有与外界交换物质、能量、信息的系统才能对抗熵增；封闭等于缓慢死亡 → 分析时的提问：「它的开放接口是什么（新人、新技术、新市场、新信息）？当前的封闭是主动保护还是惰性？保护的代价是不是慢性死亡？」

- **麦克斯韦妖（信息对抗熵增）**：思想实验中的"妖"靠获取分子速度信息做分拣，不直接做功即可降熵——信息是负熵，但获取和处理信息本身有成本 → 分析时的提问：「这个系统里谁在扮演'分拣者'（筛选机制、规则、把关人）？它靠信息还是靠蛮力维持秩序？获取关键信息的成本是否被低估？」

- **自由能**：能做有用功的是自由能而非总能量；资源总量≠可调动资源 → 分析时的提问：「账面资源里有多少是真正可支配的'自由能'（可动用现金、可投入人力、可分配时间），多少是被锁死的名义存量？」

- **不可逆性（时间之箭）**：打碎容易复原难，大量过程不可逆，修复成本远高于预防成本 → 分析时的提问：「这个动作造成的损伤可逆吗？若不可逆或修复极贵，值得用多高的前置成本去预防？」

**典型适用场景**：

- 诊断组织为何无人管理就自然走向官僚化、僵化、脏乱差。
- 评估一个系统（社区、产品、身体、生态）的长期可持续性与续命成本。
- 判断对一个衰败系统该"持续输血维持"还是"推倒重建"。

**常见误用**：

- 把"熵增"当万能标签解释一切衰败，却说不清具体是哪条流断了、哪种无序在增加。
- 忽略开放系统的存在，误信"混乱必然加剧"而放弃干预，或用蛮力对抗而不引入信息与交换。

## 模块2：系统论

**一句话定位**：不看零件看回路——系统的行为由要素间的连接与反馈结构决定，而非由单个要素的优劣决定。

**核心模型**：

- **要素-连接-目标**：系统三件套：看得见的要素、看不见但更要命的连接、决定整体行为的目标；换要素影响最小，换目标影响最大 → 分析时的提问：「要素有哪些？连接关系是什么？系统真正的目标是什么（由实际行为反推，而非听其宣称）？三者中动哪个会根本改变局面？」

- **正/负反馈回路**：正反馈（增强回路）滚雪球、自我强化；负反馈（调节回路）求稳定、拉向目标；系统行为是两者博弈的结果 → 分析时的提问：「主导回路是哪个？正反馈的滚雪球引擎是什么？负反馈的刹车装在哪、会不会踩得太迟？」

- **存量与流量**：存量是浴缸水位（积累量），流量是进出水龙头（变化率）；人盯流量，系统由存量决定 → 分析时的提问：「关键存量是什么（信任、技能、现金、用户、口碑）？流入流出各是多少？要改变存量，拧哪个水龙头杠杆最大？」

- **时间延迟**：行动与结果之间必有延迟；延迟导致过度反应、振荡与误判，在负反馈回路中尤其危险 → 分析时的提问：「这个决策的效果多久才显现？当前数据反映的是多久之前的动作？我们会不会因等不及而过度加码，或因没耐心而提前放弃？」

- **系统杠杆点（Meadows）**：干预点效力由弱到强：参数调节 < 缓冲器与存量结构 < 信息流 < 规则与激励 < 自组织能力 < 系统目标 < 范式（心智模式） → 分析时的提问：「我们拧的是哪一层杠杆？是不是只在调参数（加钱、加人、加KPI），而回避了改规则、改目标、改范式？」

- **系统陷阱**：经典病态结构——公地悲剧（个体理性集体毁灭）、目标侵蚀（标准悄悄滑坡）、富者愈富（正反馈垄断）、转嫁负担（治标成瘾损害治本能力）、政策阻抗（子系统目标互搏） → 分析时的提问：「这个困局对应哪种经典陷阱？大家在薅公共资源吗？标准在滑坡吗？是在用止痛药掩盖病灶吗？」

- **系统边界**：边界划在哪决定你看见什么、漏掉什么；被划到界外的"外部性"常常恰是问题根源 → 分析时的提问：「我画的系统边界把谁排除在外了？被归为'外部环境'的因素里，有没有其实应纳入系统内的关键互动方？」

- **结构决定行为**：同样的人放进不同结构会做出不同行为；归因于人品之前，先归因于结构 → 分析时的提问：「这个'人的问题'换谁来都会发生吗？如果换谁都犯错，那是结构的错——结构错在哪一环？」

**典型适用场景**：

- 分析反复出现、久治不愈的问题（减肥反弹、组织内耗、城市拥堵、越管越乱）。
- 设计干预方案时选择发力层级，避免只调参数。
- 解释"为什么换了几个人、几轮政策，问题依旧"。

**常见误用**：

- 画了一堆回路图却不指认主导回路和杠杆点，沦为装饰品。
- 忽略时间延迟，用当期数据评价远期动作，导致频繁地过度纠正。

## 模块3：工程学

**一句话定位**：在约束条件下用确定性方法交付可靠结果——先拆得动，再扛得住，还能复用。

**核心模型**：

- **分解与模块化**：把复杂系统拆成高内聚、低耦合的模块，接口清晰、可独立开发测试替换 → 分析时的提问：「这个大问题能否切成模块？各模块的接口是什么？哪个模块最脆弱、最该可替换？是否存在'改一处动全身'的恶性耦合？」

- **冗余设计**：关键路径必须有备份（双引擎、备胎、数据多副本）；冗余看似浪费，实为可靠性的价格 → 分析时的提问：「单点故障在哪里？它挂了是不是全链条全挂？为关键节点加备份的成本，比起故障损失是否划算？」

- **复用与标准化**：成熟方案不重复造轮子；标准件、标准流程降低成本与出错率，把创造力留给真正的创新点 → 分析时的提问：「这件事里哪些部分已有现成可靠方案可直接复用？真正需要原创的是哪10%？我们是否在重复发明一个更差的轮子？」

- **MVP与快速迭代**：先做最小可行产品验证核心假设，用真实反馈代替闭门推演，小步快跑、快速纠错 → 分析时的提问：「这个计划的核心假设是什么？验证它所需的最小版本是什么、多久能拿到真实反馈？大而全的设计里，哪些是未经验证的幻想？」

- **鲁棒性**：好系统不依赖理想条件，能在输入波动、环境恶化、操作失误下仍然工作 → 分析时的提问：「这个方案对前提假设有多敏感？假设偏了20%还成立吗？压力测试（最坏情况）下它会优雅降级还是直接崩溃？」

- **约束与权衡（没有银弹）**：工程即权衡——成本、质量、速度、范围不可兼得，任何方案先问约束 → 分析时的提问：「硬约束是什么（预算、时间、物理极限、法规）？我们宣称'全都要'的地方，实际正在牺牲哪一项？」

- **故障模式分析（FMEA）**：预先枚举一切可能的故障模式，按概率×严重度×可检测性排优先级，对高危项先行设防 → 分析时的提问：「最可能以哪几种方式失败？每种失败的概率、后果、事前可检测性如何？排第一的故障模式有预案吗？」

**典型适用场景**：

- 评估方案、计划、架构的可行性与可靠性，找单点故障。
- 设计组织流程、产品架构、应急预案。
- 判断项目该"继续打磨"还是"先上线拿反馈再说"。

**常见误用**：

- 过度工程——为想象中的需求加冗余和抽象，成本远超收益（YAGNI 原则：你不会需要它）。
- 把 MVP 当借口交付残次品：MVP 用于验证假设，不是偷工减料的遮羞布。

## 模块4：函数思维

**一句话定位**：把问题抽象成"输入→输出"的映射，盯住关键变量与变化率，判断身处曲线的哪一段。

**核心模型**：

- **输入-输出映射**：任何结果都可视为若干输入变量的函数；改变不了输出，就先检查输入与映射关系 → 分析时的提问：「想改变的这个输出是哪些输入的函数？各输入的权重与可控性如何？花在不可控变量上的精力是否过多？」

- **变量分离**：多变量纠缠时固定其余、单变量分析（偏导思维），先找出主变量 → 分析时的提问：「这几个纠缠变量能否分离考察？一次只动一个，哪个的边际影响最大？相关性里是否藏着混淆变量？」

- **指数与复利**：增长率作用于存量本身则呈指数；前期平缓得令人怀疑，后期陡峭得超出直觉；时间与增长率比本金更重要 → 分析时的提问：「这是线性增长还是复利增长？若是复利，'利率'是什么、能否再提高一个点？我们是否在用线性直觉预判指数过程（传播、口碑、技术采纳）？」

- **边际**：决策不看总量看边际——下一单位投入带来多少产出；边际收益递减是普遍规律，理性人在边际收益=边际成本处停手 → 分析时的提问：「再多投一份资源，边际产出多少、是否已低于边际成本？我们是在边际收益最高的环节加码，还是在已递减的领域继续堆量？」

- **极值与拐点**：最优值常在导数为零处；拐点（二阶导变号）是加速变减速、量变转质变的前兆 → 分析时的提问：「这个指标是否并非越大越好、而是存在极值点？当前是否正接近拐点（增速见顶、成本陡升的临界区）？」

- **S曲线**：技术、业务、技能的成长多呈S形：起步慢、爆发快、成熟平；一条曲线见顶前要启动第二条 → 分析时的提问：「我们在这条S曲线的哪一段——酝酿期、爆发期还是平台期？平台期的投入产出比还划算吗？第二曲线何时启动（答案：第一条还在增长时）？」

- **凸性与凹性**：凸函数（损失有底、收益无上限，如期权、低成本试错）从波动中受益；凹函数相反，厌恶波动 → 分析时的提问：「这个策略的收益函数是凸还是凹？下行有底、上行不封顶的事可以大胆多试；上行有限、下行无底的事要极度小心——当前是哪种？」

**典型适用场景**：

- 增长预测与资源分配：线性、指数还是S形，决定策略完全不同。
- 判断投入该加码还是收手（边际视角），何时启动第二曲线。
- 识别业务、技能、市场的生命周期阶段，避免用错阶段的打法。

**常见误用**：

- 手握函数模型却无真实数据，拍脑袋填参数，输出"精确的错误"。
- 把历史曲线简单外推，无视S曲线终将见顶——树长不到天上。

## 模块5：复杂性科学

**一句话定位**：大量简单个体的局部互动会涌现出整体无法预测的新性质——放弃控制幻觉，设计演化环境而非设计结果。

**核心模型**：

- **涌现**：整体大于部分之和；宏观性质（意识、市场、蚁群智慧）无法从个体属性直接推导，也无法还原 → 分析时的提问：「这个整体现象是哪个层级涌现的？只盯着个体层面（员工、神经元、单只股票）分析，是否漏掉了互动结构这个真正成因？」

- **自组织**：无需中央指挥，简单规则+局部互动即可自下而上形成秩序（鸟群、市场、开源社区） → 分析时的提问：「这里的秩序是设计出来的还是长出来的？能否不加强控制，而改几条简单规则（激励、信息透明、局部互动机制）让秩序自己涌现？」

- **混沌与蝴蝶效应**：确定性系统对初始条件极端敏感，微小误差被指数放大，长期行为原则上不可预测（天气、股市） → 分析时的提问：「这个系统是混沌型的吗？若是，长期精确预测本就是幻觉——是否该转向'情景预案+快速响应'，而非追求精确点预测？」

- **幂律分布**：复杂系统常产出幂律（长尾）而非正态：少数节点占绝大多数资源与影响，均值无意义，尾部不可忽视 → 分析时的提问：「这个领域的分布是正态还是幂律？若是幂律，'平均值'是否在误导决策？头部效应有多极端——该押注头部还是广撒网赌长尾？」

- **相变与临界点**：连续量变积累到阈值引发不连续质变（水结冰、舆情爆发、生态崩溃）；临界点附近系统极度敏感 → 分析时的提问：「系统存在临界阈值吗？当前距相变多远？有没有先行指标（波动加剧、恢复变慢）显示正在逼近临界点？」

- **网络效应**：节点价值随连接数增长（价值∝n²量级），强者愈强；冷启动是生死关，枢纽节点决定传播 → 分析时的提问：「这个产品的价值随用户增长而增长吗？冷启动的最小网络密度怎么达到？网络中的关键枢纽是谁——拿下或失去它们各意味着什么？」

- **分形与自相似**：复杂系统的局部与整体常自相似，同一模式在不同尺度重复出现 → 分析时的提问：「这个问题在更大或更小尺度上是否重演（个人-团队-公司-行业）？某尺度验证过的解法能否迁移到相邻尺度？」

**典型适用场景**：

- 理解市场、舆论、生态、交通等多主体互动系统，判断"能预测到什么程度"。
- 设计平台、社区、生态型机制：定规则而非控结果。
- 评估平台型业务的护城河与冷启动策略。

**常见误用**：

- 把一切复杂现象说成"涌现/混沌"然后放弃分析——复杂性不是免分析的借口。
- 用线性模型硬套幂律世界，如用平均工资理解收入、用平均回报理解风投。

## 模块6：概率统计

**一句话定位**：世界是不确定的——用概率代替确定论，用基础比率和证据更新代替直觉，在分布而非个案上思考。

**核心模型**：

- **贝叶斯更新**：先验概率×证据似然→后验概率；观点应随证据持续修正，更新幅度取决于证据的区分度 → 分析时的提问：「我的先验是多少？这条证据在假设成立/不成立两种情况下出现的概率各是多少（似然比）？更新后的后验是多少——我是否看了证据却纹丝不动，或反应过度？」

- **基础概率（基率）**：个案判断前先查该类事件的基础发生率；罕见事件+不完美的检测=阳性大多是假阳性 → 分析时的提问：「这类事的基础发生率是多少？我是否被鲜活个案带跑、忘了分母多大？罕见病检测阳性时，真患病的概率其实有多低？」

- **大数定律**：样本量越大，观测均值越收敛于真实期望；小样本波动巨大，极端表现多出自小样本 → 分析时的提问：「这个结论基于多大样本？小样本的惊人数字（某小店转化率50%、某新股民翻倍）是否只是噪音？多少样本才够下结论？」

- **均值回归**：极端表现之后倾向回归平均；极高极低的单期结果多含运气，下一次大概率没那么极端 → 分析时的提问：「这次极好/极差的表现里实力占多少、运气占多少？我们是否在奖励/惩罚一个即将自动回归均值的随机波动？」

- **幸存者偏差**：只看到"活下来"的样本，系统性忽略沉默的失败者，归因严重失真（成功学、返航轰炸机的弹孔） → 分析时的提问：「这个数据集里失败者、退出者、沉默者在哪？只采访了赢家吗？正确的问题或许是'失败者有什么不同'？」

- **相关≠因果**：相关可能来自因果、反向因果、共同原因或纯巧合；坐实因果需随机对照、自然实验或机制证据 → 分析时的提问：「有没有可能是反过来的（B导致A）？有没有第三变量同时驱动两者？有什么机制或准实验证据能坐实因果？」

- **期望值**：决策价值=各结果概率×损益之和；长期重复中选期望为正的策略，同时盯住方差与破产风险 → 分析时的提问：「期望值是多少？即使期望为正，极端坏结果会否一次让我出局（仓位管理）？期望为负的事，我们是否因'万一呢'一直在做？」

- **辛普森悖论**：分组数据中成立的趋势，合并后可能反转（混杂变量在各组分布不均所致） → 分析时的提问：「这个总体结论按关键维度分组后还成立吗？合并数据是否掩盖了分组内相反的趋势？」

- **赌徒谬误**：独立随机事件没有记忆，人们却从小样本强行读出规律（"连涨必跌""连败该转运"） → 分析时的提问：「这些事件相互独立吗？若独立，'已经连输这么多该赢了'纯属幻觉；若不独立，真正的依赖机制是什么？」

**典型适用场景**：

- 不确定性下的决策：投资、招聘、医疗、战略选择。
- 评估数据结论与研究报告的可信度，拆穿统计陷阱。
- 复盘"好决策坏结果/坏决策好结果"，把决策质量与结果质量分开。

**常见误用**：

- 结果论：事后用结果倒推决策质量，忽略决策时的信息与概率。
- 把概率当精确科学，对无法量化的不确定性（黑天鹅）强行赋值，制造虚假的安全感。

## 模块7：信息论

**一句话定位**：信息是对不确定性的消除——衡量它、提纯它，并在噪音与成本约束下设计它的传递方式。

**核心模型**：

- **香农熵**：信息熵度量不确定性的总量：事件越不可预测，其发生携带的信息量越大；各结果等概时熵最大 → 分析时的提问：「这个信源的不确定性有多高？若结果总是八九不离十，每次'汇报'传递的信息量其实接近零——这个信息流真的需要存在吗？」

- **信噪比**：信号是有用信息，噪音是干扰；提升信噪比两条路：增强信号或削减噪音，后者常被忽视且更便宜 → 分析时的提问：「这个沟通/报告/界面的信噪比是多少？读者要的信息被多少噪音稀释？砍掉哪些内容能不加新信息反而提高传递效率？」

- **冗余度**：冗余是抗噪的保险费——关键信息要重复、多渠道、多形式传递以防丢包；但冗余过多=啰嗦，信息量趋零 → 分析时的提问：「这条关键信息只传了一次、走了一个渠道吗？丢包风险多大，值得加多少冗余（复述、确认、备份）？反过来，冗余是否已高到让读者直接跳过？」

- **编码与压缩**：好编码用最短符号表达最高频信息（霍夫曼编码思想）；压缩=提炼本质模式，有损压缩先丢最不重要的 → 分析时的提问：「这份表达能否压缩——用更少的字传达同样信息？高频概念有没有'短码'（术语、图标、约定俗成的暗号）？压缩时会丢掉哪些关键限定？」

- **信息即意外**：信息量=惊讶程度；完全可预期的话不含信息，意外越大信息越多、但也越难被相信 → 分析时的提问：「这条信息里真正'意外'的部分是什么？若每句对方都能预判，我的信息量就是零——核心意外点提炼出来了吗？它意外到让人不信了吗？」

- **信道容量**：任何信道都有传输上限，超载必然丢包失真；对方的时间与注意力是硬约束 → 分析时的提问：「这条信道（对方的时间、注意力、会议时长、带宽）容量还剩多少？我要传的信息超载了吗——该压缩信息，还是换更宽的信道？」

**典型适用场景**：

- 打磨沟通、写作、演讲、汇报：删噪音、加关键冗余、提炼意外点。
- 设计组织的会议、报告、数据看板，砍掉信息量趋零的例行输入。
- 评估信息源（渠道、订阅、数据流）的真实价值，区分"数据量大"与"信息量大"。

**常见误用**：

- 混淆数据量与信息量——转述全网皆知的事不产生任何信息。
- 过度压缩牺牲准确性：摘要把关键限定条件也压掉，接收方得到的是错误的"精炼"。

## 模块8：脑科学

**一句话定位**：大脑是三层叠装的演化产物且终身可塑——顺着硬件特性设计行为，比用意志力对抗硬件有效得多。

**核心模型**：

- **三重大脑**：爬行脑（本能、生存反射）、哺乳脑（情绪、边缘系统）、理性脑（新皮层）依次演化叠装；情绪与本能的优先级高于理性，理智常被"劫持" → 分析时的提问：「当事人此刻被哪层大脑驱动？我在用理性论证回应一个情绪/生存层面的反应吗？要改变行为，是否该先安抚情绪脑再谈道理？」

- **神经可塑性**：大脑终身可塑，"一起放电的神经元连在一起"（赫布定律）；重复的行为与思维会物理性重塑神经通路 → 分析时的提问：「这个习惯/能力对应的回路被重复激活了多少次？想弱化旧回路，是在强行压制，还是在用新回路替代（替代比戒断有效）？」

- **多巴胺奖赏回路**：多巴胺驱动"想要"而非"喜欢"，由预期奖励与不确定性激发（变动比率强化最成瘾）；习惯=触发→行为→奖励的回路 → 分析时的提问：「这个行为背后的奖赏回路是什么（触发点、行为、即时奖励）？产品/机制是否在用间歇性不确定奖励制造沉迷？戒断方案是砍回路还是换奖励？」

- **峰终定律**：人对一段体验的记忆≈峰值时刻与结束时刻的平均，过程时长几乎被忽略 → 分析时的提问：「这段体验（服务、旅行、会议、课程）的情绪峰值和结尾分别是什么？资源该砸在制造一个高峰+一个好结尾，还是均匀铺开？现在的结尾是否草草收场？」

- **刻意练习**：有效练习=明确目标+走出舒适区+即时反馈+高度专注+专攻薄弱环节；单纯重复一万次只是熟练地固化错误 → 分析时的提问：「当前练习是在舒适区重复还是在学习区拉伸？反馈是否即时且具体？训练内容瞄准的是最弱的子技能，还是最顺手的部分？」

- **心流**：挑战略高于技能（约4%法则）+明确目标+即时反馈时，进入全神贯注的最优体验，产出与幸福感双高 → 分析时的提问：「当前任务的挑战-技能匹配落在哪区——太难焦虑、太易无聊、还是恰在心流通道？能否调难度或提技能，把人推回通道内？」

- **大脑是预测机器**：大脑不断预测输入、用预测误差修正模型；惊讶=预测误差=学习的原料，完全在预料之中的输入几乎不被加工 → 分析时的提问：「什么会让人真正记住——重复还是意外？我的教学/沟通/内容制造并利用'预测误差'了吗？还是全在对方的预测之内、左耳进右耳出？」

**典型适用场景**：

- 设计产品、内容、游戏的留存与上瘾机制（或反过来：拆解他人的成瘾设计）。
- 制定个人学习、健身、习惯养成方案，用回路替代而非意志力压制。
- 解释并干预情绪化决策、拖延、沟通失效——先处理情绪层再处理认知层。

**常见误用**：

- 神经神话化：滥用"左脑理性右脑创意""大脑只开发10%"等伪科学说法。
- 把多巴胺简单等同于"快乐物质"，误判动机机制（它管的是渴望与预期，不是享受）。

## 模块9：生理学

**一句话定位**：身体是追求动态平衡的适应性机器——压力+恢复=成长，节律与用进废退是底层运行法则。

**核心模型**：

- **内稳态**：机体通过负反馈把核心指标（体温、血糖、pH）维持在狭窄区间；扰动会被系统自动拉回，改变需要持续超阈值的刺激 → 分析时的提问：「这个'体质/状态'是不是一个内稳态设定点？单次干预为何总被弹回（节食反弹）？移动设定点需要多大幅度、多持久的刺激？」

- **应激与超量恢复**：适度压力造成微小损伤，充分恢复后机能超过原有水平（健身、免疫、心理韧性同此理）；只有压力没有恢复=损耗，没有压力=萎缩 → 分析时的提问：「当前的压力-恢复配比健康吗？剂量落在'超量恢复区'还是'崩溃区'或'无效区'？恢复时间给够了吗——增长发生在恢复期，而非压力期？」

- **昼夜节律**：生物钟调控激素、体温、认知与代谢的24小时周期；顺应节律事半功倍，熬夜与倒班的代价是全身系统的长期错位 → 分析时的提问：「关键任务（决策、创造、运动）是否排在个人节律的峰值时段？当前的透支方案是否在借昼夜节律的高利贷——利息何时显现？」

- **用进废退**：器官与能力遵循"用则强化、不用则退化"（肌肉、骨密度、认知、语言）；维持需要持续的最小剂量刺激 → 分析时的提问：「这项能力/资产多久没用了，正以什么速率退化？维持它的最小有效剂量是多少？哪些'暂时搁置'其实是永久退化的开始？」

- **毒物兴奋效应（Hormesis）**：剂量决定毒性——低剂量有害刺激（运动、寒冷、禁食）激活修复机制反而有益，高剂量才致命；"一点都不能碰"的线性外推是错的 → 分析时的提问：「这个'有害因素'的剂量-效应曲线是什么形状？我们是在完全规避它（可能丧失低剂量收益），还是在安全剂量内利用它？规避本身的成本是什么？」

**典型适用场景**：

- 设计健身、学习、抗压训练方案：压力与恢复的节奏比强度本身更关键。
- 评估工作制度的健康可持续性（加班、倒班、连续冲刺），计算隐性生理债务。
- 理解"坚持不下去"的生理学根源（设定点、恢复不足、节律错位），据此设计方案而非归咎于意志力。

**常见误用**：

- 把"超量恢复"当无限加压的许可证，忘了恢复是公式的一半。
- 把生理模型生硬套到组织/社会层面而不检验边界——组织不是有机体，类比只是脚手架。

## 附：跨模块速查（何时翻哪块）

- 判断一个系统为什么越管越乱、越放越衰败 → 模块1（熵）、模块2（系统陷阱）
- 设计可落地的方案、架构、流程、预案 → 模块3（工程学）、模块2（杠杆点）
- 预测增长、分配资源、判断加码或收手 → 模块4（函数思维）、模块6（期望值）
- 面对多主体、无法精确预测的环境 → 模块5（复杂性）、模块6（概率）
- 评估证据、拆穿数据结论、复盘决策质量 → 模块6（概率统计）
- 打磨表达、沟通、汇报、信息产品 → 模块7（信息论）
- 设计让人行动、坚持、上瘾的机制，或反向拆解之 → 模块8（脑科学）
- 设计训练节奏、评估个人或组织的可持续性 → 模块9（生理学）、模块8（刻意练习）
