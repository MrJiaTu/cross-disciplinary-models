## 模块1：古代哲学

**一句话定位**：提供看待变化、行动与心性的底层操作系统——在不确定性中保持方向感与内心稳定。

**核心模型**：
- **反者道之动（道家）**：事物发展到极点必然向反面转化，循环往复是道的运动方式
  → 分析时的提问：「这个趋势是否已接近极端？反转的条件和信号是什么？」
- **无为（道家）**：不是不做事，而是不妄为——顺应事物自身规律，在最省力的节点介入
  → 分析时的提问：「我是在顺水推舟还是逆流硬干？哪个动作是多余的人为干预？」
- **柔弱胜刚强（道家）**：柔弱者具有适应性、存续力和渗透力，刚强者易折
  → 分析时的提问：「这个系统里谁看起来弱但活得久？刚性方案会在哪个应力点断裂？」
- **上善若水（道家，补充）**：水善利万物而不争，处众人之所恶；最高的策略形态是像水一样利他、居低、随形而势不可挡
  → 分析时的提问：「我能否用成就他人而非争夺的方式达成目标？最低、最不被争抢的位置藏着什么势能？」
- **中庸（儒家）**：不偏不倚、无过无不及，在具体情境中把握最恰当的度，而非简单折中
  → 分析时的提问：「两个极端各自的代价是什么？当前情境下恰到好处的『度』在哪里？」
- **修齐治平（儒家）**：修身→齐家→治国→平天下，改变外部世界从改变自己的最近圈层开始，逐圈外推
  → 分析时的提问：「我想影响的圈层与我实际可控的圈层之间，隔了几层？我这一环修好了吗？」
- **控制二分法（斯多葛）**：把事情分为「我能控制的」与「我不能控制的」，全部精力投入前者，对后者平静接受
  → 分析时的提问：「这个烦恼里，哪些变量在我控制之内？我有多少情绪花在了不可控项上？」
- **消极想象（斯多葛，补充）**：预先在想象中经历最坏结果（premeditatio malorum），以消解恐惧、校准珍惜、预置预案
  → 分析时的提问：「最坏情况具体长什么样？我能否承受？哪个预案现在就该准备？」
- **无常（佛家）**：一切现象皆处于生灭变化之中，没有任何状态会永恒持续
  → 分析时的提问：「我是否把当前的顺境/逆境当成了常态？哪些前提正在悄悄变化？」
- **缘起性空（佛家）**：万物依因缘而生、没有独立不变的自性；任何存在都是条件网络的产物
  → 分析时的提问：「这个结果依赖哪些条件（因缘）？抽掉哪个条件它就瓦解？」
- **四圣谛（佛家，补充）**：苦（承认问题）→集（找到成因）→灭（确认可解）→道（执行路径），是一套古老的结构化问题解决框架
  → 分析时的提问：「我是否在回避承认『苦』？成因（集）找准了吗？通往『灭』的路径拆出来了吗？」

**典型适用场景**：
- 趋势极值判断与拐点预判（反者道之动、无常）
- 战略节奏与介入时机选择：何时进、何时守、何时不干预（无为）
- 高压与不确定环境下的情绪管理与决策稳定（控制二分法、消极想象）
- 长期竞争中的韧性建设与姿态设计（柔弱胜刚强、上善若水）
- 结构性问题的根因拆解（缘起性空、四圣谛）
- 个人影响力扩张的次序设计（修齐治平）

**常见误用**：
- 把「无为」当成不作为、躺平的借口（无为是精准作为，不是放弃作为）。
- 把「中庸」理解成和稀泥、各打五十大板（中庸要求的是情境中的最优解，往往立场鲜明）。
- 用「无常」消解一切行动的意义（无常恰恰说明窗口期有限，更应果断）。
- 用控制二分法逃避责任（对「不可控」的判定本身常被偷懒扩大）。
- 把「柔弱」误读为软弱可欺（柔弱是主动选择的策略姿态，背后是对时势的判断）。
- 消极想象做成焦虑反刍（它的终点是预案与珍惜，不是反复咀嚼恐惧）。

## 模块2：现代哲学

**一句话定位**：提供关于自我、真理与认识的现代工具——回答「我是谁、什么算对、如何看清楚」。

**核心模型**：
- **存在先于本质（存在主义）**：人没有预定好的「本质」，你是你一系列选择的总和；本质由行动塑造
  → 分析时的提问：「我在用『我就是这样的人』逃避哪个本可以做的选择？下一步行动在把我塑造成什么？」
- **自我塑造（存在主义）**：通过主动承担选择的全部责任来定义自己，拒绝把定义权交给环境与他人
  → 分析时的提问：「这个决定是我自己做的，还是默认了别人的脚本？」
- **荒诞与反抗（加缪，补充）**：世界本无先验意义；承认荒诞后不逃避、不自欺，以持续的反抗、自由与激情活在当下
  → 分析时的提问：「当外部意义崩塌时，支撑我继续行动的是什么？我是在反抗还是在认命？」
- **效果即真理（实用主义）**：一个观念的意义与价值在于它带来的实际后果；有用且经得起实践检验的才是真的
  → 分析时的提问：「这个理论/方案落地后会产生什么可观察的差别？如果两种说法效果相同，争论还有意义吗？」
- **回到事情本身（现象学）**：悬置先入为主的理论与立场，直接描述现象呈现的样子，从一手经验出发
  → 分析时的提问：「我看到的是事实本身，还是被概念、KPI、叙事过滤后的版本？原始数据和一线现场说了什么？」
- **可证伪性（证伪主义，波普尔）**：一个理论科学的标志是它能被经验证伪；无法被任何观察推翻的命题不是科学命题
  → 分析时的提问：「什么证据出现时，我愿意承认自己错了？我的判断是否被设计成了『怎么都对』？」
- **范式与范式转移（库恩，补充）**：科学在范式内做常规解题，反常积累到临界点引发范式革命；范式决定人们能提出什么问题
  → 分析时的提问：「这个领域的现行范式是什么？哪些『反常』正在积累到必须换范式的程度？」

**典型适用场景**：
- 个人定位、职业转型与身份危机（存在主义）
- 方案评估与理论之争的裁决：谁的效果好谁对（实用主义）
- 用户研究、一线调研、破除汇报滤镜（现象学）
- 评估预测、模型、商业模式是否靠谱（证伪主义）
- 行业范式判断：什么时候该守旧范式、什么时候押新范式（库恩）

**常见误用**：
- 把实用主义庸俗化为「有用就是正义」「成王败寇」（它讨论的是真理标准，不是价值豁免）。
- 把「回到事情本身」当成拒绝一切理论（现象学是暂时悬置而非永久抛弃框架）。
- 误用证伪主义否定一切统计性、概率性知识（可证伪针对全称命题，概率命题需用贝叶斯思路处理）。
- 用「存在先于本质」为反复横跳背书（自由选择伴随全部责任，不是免责卡）。
- 把「范式转移」当时髦词滥用，把普通迭代也喊成革命（范式革命的标志是旧范式无法解释的反常成堆）。

## 模块3：投资大师思维模型

**一句话定位**：把资本市场的生存智慧移植为通用决策纪律——管理风险、守住边界、逆向思考、延迟满足。

**核心模型**：
- **安全边际（格雷厄姆）**：以显著低于内在价值的价格买入，为判断错误、坏运气和未知风险预留缓冲
  → 分析时的提问：「如果我错了20%-30%，这个决策还成立吗？我的缓冲垫有多厚？」
- **市场先生（格雷厄姆，补充）**：把市场波动拟人化为情绪无常的报价员——他是仆人不是向导；你利用他的情绪，不被他感染
  → 分析时的提问：「当前的报价/评价反映价值，还是反映『市场先生』的情绪？我在利用波动还是被波动利用？」
- **能力圈（巴菲特）**：只在自己真正懂的领域下注；圈的大小不重要，清楚圈的边界才重要
  → 分析时的提问：「这个问题在我的能力圈内还是圈外？我是真懂，还是只是熟悉？」
- **护城河（巴菲特）**：企业抵御竞争的结构性优势：无形资产、转换成本、网络效应、成本优势
  → 分析时的提问：「这个优势是结构性的还是阶段性的？竞争对手复制它需要多大代价？」
- **第二层思维（霍华德·马克斯）**：第一层思维看直接因果，第二层思维追问「大家都知道了会怎样」——预期已计入价格，超额收益来自与共识不同且正确的判断
  → 分析时的提问：「我的结论和共识一样吗？如果一样，机会还剩多少？共识错在哪？」
- **逆向投资（邓普顿/马克斯）**：最大机会出现在极度悲观时，最大风险潜伏在极度乐观时；他人恐慌时贪婪，他人贪婪时恐慌
  → 分析时的提问：「当前情绪是极端悲观还是极端乐观？价格里计入了多少恐惧/贪婪？」
- **长期主义与复利**：时间与再投入让微小优势指数级放大；复利的敌人是中断（重大亏损、频繁换道）
  → 分析时的提问：「这件事做十年会累积成什么？什么会让我的复利中断？」
- **芒格检查清单（查理·芒格）**：决策前系统过一遍常见误判心理与跨学科模型清单，用流程对抗大脑的天然缺陷
  → 分析时的提问：「激励、嫉妒、确认偏误、沉没成本……这个决定里哪些心理偏差在起作用？」

**典型适用场景**：
- 投资与一切重大资源投入决策（安全边际、市场先生）
- 职业与创业方向选择：在哪下注、凭什么赢（能力圈、护城河）
- 评估热门赛道与群体共识的含金量（第二层思维、逆向投资）
- 构建个人/组织长期优势与节奏（复利、长期主义）
- 重大拍板前的系统性风险审计（检查清单）

**常见误用**：
- 把安全边际理解成「越便宜越好」（廉价劣质资产没有安全边际，安全边际锚定的是价值而非价格）。
- 用能力圈拒绝学习新东西（能力圈应当缓慢扩大，边界清晰不等于边界封死）。
- 为逆向而逆向（共识大多数时候是对的；逆向的前提是第二层思维给出独立论证）。
- 把长期主义当成永不止损的借口（长期持有的前提是基本面未变，错了要认）。
- 滥用护城河概念，把一切先发优势都称为护城河（先发不是护城河，结构性复制成本才是）。

## 模块4：自我管理

**一句话定位**：把认知转化为产出的执行系统——让正确的事持续发生，而不依赖意志力硬撑。

**核心模型**：
- **GTD（戴维·艾伦）**：捕获→厘清→组织→回顾→执行；把大脑从「记事情」中解放出来只做「想事情」
  → 分析时的提问：「我脑子里还挂着多少未捕获的事？每件悬而未决之事的『下一步行动』具体是什么？」
- **习惯回路（杜希格）**：暗示→惯常行为→奖赏；改变习惯不是消灭回路，而是保留暗示与奖赏、替换中间的惯常行为
  → 分析时的提问：「这个坏习惯的暗示和奖赏是什么？哪个替代行为能给同样的奖赏？」
- **目标倒推（以终为始）**：从期望的终点状态反向推导各阶段里程碑与当下该做的事
  → 分析时的提问：「三年后要的结局是什么？倒推回来，今年、本季度、本周必须完成什么？」
- **要事第一（柯维，补充）**：按重要/紧急分四象限，把固定时间块优先投给「重要不紧急」——它在事前消除危机
  → 分析时的提问：「我的日程是被紧急事项驱动，还是被重要事项牵引？本周给第二象限留了几块完整时间？」
- **精力管理**：管理的对象是精力而非时间；体能、情绪、注意力和意义感四个维度决定单位时间产出
  → 分析时的提问：「我一天的精力高峰在何时？最难的任务排在了高峰还是低谷？」
- **两分钟法则**：能在两分钟内做完的事立即做；新习惯从两分钟的微缩版开始
  → 分析时的提问：「哪些事现在顺手就能清掉？这个新习惯能否缩到两分钟版本先跑起来？」
- **心流（契克森米哈赖，补充）**：挑战与技能匹配、目标清晰、反馈即时时进入的最优体验状态，是深度产出的引擎
  → 分析时的提问：「这项任务的挑战度与我的技能匹配吗？目标和即时反馈是否明确？」
- **复盘机制（AAR）**：回顾目标→评估结果→分析原因→总结规律，把每次行动转化为经验资产
  → 分析时的提问：「预期与实际的差距是什么？哪些因素可复用、哪些必须改？下次的验证动作是什么？」

**典型适用场景**：
- 任务过载、遗漏频繁、脑子像塞满的浏览器标签页（GTD）
- 建立好习惯或戒除坏习惯（习惯回路、两分钟法则）
- 中长期规划拆解与优先级排序（目标倒推、要事第一）
- 深度工作与高质量产出安排（精力管理、心流）
- 项目收尾、组织学习与个人认知升级（复盘机制）

**常见误用**：
- 把GTD做成「收藏家谬误」：花大量时间整理清单却不执行（系统是为行动服务的）。
- 目标倒推时忽视路径依赖与不确定性（倒推是地图不是铁轨，需随反馈修正）。
- 两分钟法则滥用导致整天处理琐事、回避深度工作（它用于清障与启动，不是主菜）。
- 复盘开成追责会或表功会（复盘只对规律负责，不对情绪负责）。
- 精力管理只盯睡眠和运动，忽视情绪与意义感两个隐形大户。

## 模块5：回到真实世界（模型综合）

**一句话定位**：防止模型用滥的元模型——所有模型都是地图，疆域才是目的。

**核心模型**：
- **单一模型陷阱（锤子综合征，芒格）**：手里只有锤子，看什么都像钉子；单一学科的模型会把复杂现实削足适履
  → 分析时的提问：「我是不是又在用最熟的那个模型套一切？换一个学科视角，问题会长成什么样？」
- **跨学科交叉验证**：同一问题用两个以上不同学科的模型独立分析，结论相互印证才可信，相互矛盾处正是认知富矿
  → 分析时的提问：「经济学、心理学、系统论分别怎么看这件事？三个结论的交集与冲突点各是什么？」
- **从模型到行动**：模型的价值以行动改变为终点；分析必须收敛为「谁在什么时间做什么、如何验证」
  → 分析时的提问：「这套分析改变了哪个具体决策？下一步最小可验证动作是什么？」
- **lollapalooza效应（芒格，补充）**：多种心理偏差与模型同向叠加时产生极端非线性后果——好得离谱或坏得离谱
  → 分析时的提问：「此刻有几个力量正指向同一方向？叠加放大后的极端情形我准备好了吗？」
- **地图不是疆域（科日布斯基，补充）**：模型是对现实的简化表征，永远不等于现实本身；当地图与疆域冲突，以疆域为准
  → 分析时的提问：「现实里的哪个细节和我的模型对不上？我该修正现实还是修正模型？」

**典型适用场景**：
- 复杂真实问题（职业、商业、社会议题）的完整分析立项
- 评审他人分析报告的质量：模型是否单一、结论是否经交叉验证
- 防止「懂得很多模型，依然过不好」的知行断裂
- 判断极端行情/极端舆情是否由多因素同向叠加驱动（lollapalooza）

**常见误用**：
- 模型集邮：以知道模型数量为荣，从不用于真实决策。
- 交叉验证走过场：先定结论，再挑两个模型来「背书」。
- 分析瘫痪：用「再验证一下」无限推迟行动（验证有成本，够用即可行动，行动后再迭代）。
- 把「地图不是疆域」当相对主义挡箭牌（承认模型不完美不等于拒绝一切模型）。

## 模块6：资本论（结构层：利益与分配）

**一句话定位**：透视一切经济组织与商业模式的底层结构——价值从哪来、被谁拿走、矛盾往哪积累；在分析框架中负责「利益与分配」这一结构层。

**核心模型**：
- **商品二重性（使用价值/交换价值）**：任何商品（含服务、内容、流量）同时是具有使用价值的物和承载交换价值的价值体；二者的背离是理解定价、泡沫与品牌溢价的钥匙
  → 分析时的提问：「这个东西的使用价值（真实效用）和交换价值（市场价格）各是多少？二者的裂口是机会还是泡沫？」
- **价值形式与资本总公式（G-W-G′，补充）**：货币不是目的而是价值形式；资本的运动是货币—商品—更多货币，增殖（G′>G）是资本存在的理由，不增殖的钱只是货币不是资本
  → 分析时的提问：「这笔钱的循环一周能增殖多少、多快？增殖来自真实价值创造还是纯粹的价差搬运？」
- **劳动力成为商品**：劳动者出卖的不是劳动而是劳动力；劳动力的价值（维持再生产所需）与其使用价值（能创造更多价值）之间的差额，是一切利润的来源
  → 分析时的提问：「这笔交易里谁在出售『能生产更多价值的能力』？买方赚取的差额来自哪里？」
- **剩余价值（绝对/相对）**：绝对剩余价值靠延长劳动时间、提高强度取得；相对剩余价值靠技术进步压缩必要劳动时间取得——这是企业压榨利润的两条基本路径
  → 分析时的提问：「这家公司的利润增长，是靠『多干』（加班、扩张）还是靠『少花』（技术、效率）？哪条路快到头了？」
- **资本积累与集中**：剩余价值再投入形成积累，竞争与信用推动资本向头部集中（积聚+集中），规模壁垒由此而来
  → 分析时的提问：「这个行业的利润正在被谁再投资、向谁集中？分散格局还能维持多久？」
- **异化劳动**：劳动者同劳动产品、劳动过程、类本质、他人相异化——当工作只剩谋生手段、人与成果彻底分离，效率与忠诚都会系统性流失
  → 分析时的提问：「这个岗位上的人能感受到自己劳动的意义和成果吗？异化程度是否在透支组织？」
- **生产力与生产关系**：生产力（技术、工具、劳动者）发展会冲击既有生产关系（产权、分配、组织形式）；不相适应时变革必然发生
  → 分析时的提问：「新技术（生产力）正在被哪种旧的生产关系（股权、雇佣、分配制度）束缚？谁先松绑谁先赢？」
- **危机的周期性**：生产无限扩张与有支付能力的需求相对不足的矛盾，使危机呈周期性爆发；过热—出清—复苏是资本运动的内在节律
  → 分析时的提问：「当前处于周期的哪个阶段？过剩产能（库存、泡沫、冗余组织）会以什么形式出清？」
- **价值创造—传递—获取三段分析（补充）**：把一家公司的业务拆到「价值创造—价值传递—价值获取」三段，检查每一段由谁承担、由谁获益
  → 分析时的提问：「创造价值的人、传递价值的渠道、获取价值的股东，三者是否错位？错位处在积累什么怨气？」

**典型适用场景**：
- 商业模式解剖：钱从哪来、凭什么持续（商品二重性、资本总公式、剩余价值）
- 劳资关系、薪酬设计与组织激励分析（劳动力商品、异化劳动）
- 行业格局演变与集中度预判、平台垄断与监管议题（积累与集中）
- 技术变革期的制度与组织变革判断（生产力与生产关系）
- 周期判断与扩张/收缩决策（危机的周期性）
- ESG与「人的因素」评估：士气、意义感、流失率的结构性根源（异化劳动）

**常见误用**：
- 把《资本论》当道德谴责书来用，而非结构分析工具（它首先是一套解释机器如何运转的理论）。
- 机械套用劳动价值论，否定风险承担、管理与稀缺要素的贡献（分析时区分「价值来源」与「分配谈判力」两个问题）。
- 忽视时代变量：数字时代的生产资料形态变化（数据、算法、注意力），需做概念迁移而非原文硬套。
- 只看分配不公，看不到积累与集中的效率功能（集中既制造矛盾也创造规模，二者要同时看见）。
- 把「异化」泛化为一切工作不开心（异化特指人与产品、过程、本质、他人的系统性分离，是结构诊断而非情绪词）。
- 用周期理论做精确择时（周期给的是位置感与方向感，不是日历；拐点只能逼近，无法掐点）。

**操作流程**：
1. **画价值链**：把分析对象（公司/行业/交易）拆成「投入—生产—流通—分配」四段，标注每一段谁出钱、谁出力、谁承担风险。
2. **定位价值来源**：用商品二重性问「真实效用 vs 市场价格」，用劳动力商品问「差额利润从谁的什么能力中来」，找出利润的真实泉眼。
3. **判定榨取路径**：增长靠绝对剩余价值（加时间加强度）还是相对剩余价值（技术与效率）？据此判断增长的可持续性与合规/舆论风险。
4. **看积累与集中**：追踪利润再投资去向，判断行业集中度走向与护城河性质（结构性壁垒还是阶段性领先）。
5. **检生产关系适配度**：对照生产力新变化（新技术、新要素），找出束缚它的旧制度/旧分配/旧组织——束缚点即变革点与机会点。
6. **校周期位置**：用库存、产能利用率、信用扩张、价格信号判断周期阶段，预判出清方式（渐进消化 or 危机式出清）。
7. **落到分配结论**：输出「谁在受益、谁在受损、矛盾在哪个环节积累、什么事件会引爆调整」四句话，作为结构层结论交给矛盾论去定主次。

## 模块7：矛盾论（定主次）

**一句话定位**：面对复杂局面时确定主攻方向的方法论——「研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。」在分析框架中负责「定主次」。

**核心模型**：
- **矛盾的普遍性**：矛盾存在于一切事物的发展过程中，贯穿每一过程的始终；没有矛盾就没有世界——分析时先默认「矛盾一定存在，没找到是我的问题」
  → 分析时的提问：「这个局面里相互对立又相互依存的力量各是什么？我真的把矛盾找全了吗？」
- **矛盾的特殊性**：不同事物的矛盾各有特点，同一事物在不同发展阶段的矛盾也各有特点；具体问题具体分析是马克思主义活的灵魂
  → 分析时的提问：「这个矛盾和别人家的、和上一阶段的有什么不同？照搬的方案哪里会水土不服？」
- **主要矛盾与次要矛盾**：在复杂过程中，必有一种矛盾居于支配地位、对发展起决定作用；全力找出并捉住主要矛盾，次要矛盾随之易解
  → 分析时的提问：「所有问题里，哪一个一解决、其他问题就好办？我现在的资源是否正砸在主要矛盾上？」
- **矛盾的主要方面**：矛盾双方中处于支配地位、决定事物性质的一方叫主要方面；事物的性质由主要方面规定
  → 分析时的提问：「这对矛盾里目前是哪一方占上风、决定着事情的性质？我评价它时用对了主导面吗？」
- **对立统一**：矛盾双方既相互排斥斗争，又相互依存、互为存在条件；只见对立不见统一，或只讲调和不见斗争，都是片面性
  → 分析时的提问：「这对立的两方各自以对方为存在条件的地方在哪？我是否把可以共存的力量当成了你死我活？」
- **两点论与重点论**：既要看到矛盾双方、看到主要与次要（两点论），又要分清主次、抓住重点（重点论）；反对一点论，也反对均衡论
  → 分析时的提问：「我的分析是不是只讲了一面？或者面面俱到却没有重点？哪20%的矛盾决定80%的走向？」
- **矛盾双方的转化条件**：主要与次要矛盾、矛盾的主要与次要方面，在一定条件下相互转化；条件变化，主次易位，策略必须跟着变
  → 分析时的提问：「什么条件出现时，现在的次要矛盾会升级为主要矛盾？哪个先行信号提示转化正在发生？」
- **对抗性矛盾与非对抗性矛盾（补充）**：矛盾的性质分对抗（利益根本冲突）与非对抗（同一目标下的方式分歧）两类；不同性质的矛盾只能用不同的方法解决，混淆性质会把内部讨论变成敌我斗争
  → 分析时的提问：「这个分歧是对抗性还是非对抗性的？我用的解决方法匹配矛盾的性质吗？」

**典型适用场景**：
- 复杂问题多线纠缠、不知从何下手（列矛盾→锁主要）
- 资源有限需要聚焦、战略优先级排序（重点论）
- 组织诊断：找准当前阶段的核心瓶颈（主要矛盾+特殊性）
- 局势研判与拐点预判：盯转化条件与先行信号（转化条件）
- 冲突管理：先定性再选方法，避免用斗争方法处理内部分歧（对抗性/非对抗性）

**常见误用**：
- 把「主要矛盾」当成「最急的事」或「声音最大的事」（紧急≠主要，主要矛盾是对全局起决定作用的矛盾，可能并不吵闹）。
- 一次锁定、终身不改：阶段变了主要矛盾也变了，锁定后必须持续检验。
- 用两点论当面面俱到的借口，回避排序（两点论必须落到重点论，否则是均衡论）。
- 只看对立斗争、忽视依存统一，把谈判与合作的可能性分析丢了。
- 混淆「矛盾的主要方面」与「主要矛盾」：前者定一对矛盾内部的性质，后者定多对矛盾之间的主次。
- 定性错误：把非对抗性矛盾当对抗性矛盾处理，把可以团结的力量推向对立面。

**操作流程**：
1. **列全部矛盾**：不加筛选地罗列局内所有相互对立、相互制约的力量与问题对（供需、快慢、质量与成本、增长与合规、个人与组织……），宁多勿漏。
2. **两两比较地位**：逐对追问「这个矛盾解决了，其他矛盾会跟着松动吗？」「这个矛盾不解决，其他努力会白费吗？」，用决定作用排序。
3. **锁定主要矛盾**：找出居于支配地位、起决定作用的那一个，用一句话写出「当前阶段的主要矛盾是___与___的矛盾」，并让全部资源向其倾斜。
4. **判定矛盾主要方面**：在主要矛盾内部，判断当前哪一方占支配地位、规定着事物性质；据此决定姿态（顺势、攻坚、防守还是等待）。
5. **坚持两点论补盲**：回看次要矛盾清单，标注其中两个最值得留意的（可能在酝酿升级），为它们设置观察哨而非投入主力。
6. **预判转化条件与信号**：写出「若___条件出现，___将取代___成为主要矛盾」，并为每个转化配一个可观察的先行信号（数据、事件、情绪）。
7. **交付行动**：把主要矛盾翻译成主攻方向，交给实践论的行动闭环；定期（阶段转换时）回到第1步重排。

## 模块8：实践论（行动闭环）

**一句话定位**：连接知与行的发动机——「实践、认识、再实践、再认识，这种形式，循环往复以至无穷，而实践和认识之每一循环的内容，都比较地进到了高一级的程度。」在分析框架中负责把矛盾论定的主次、资本论析的结构，变成行动与真知。

**核心模型**：
- **实践-认识-再实践-再认识**：认识从实践开始，经实践得到理论，再回到实践去检验和发展；认识运动是无限上升的螺旋，没有一次到位的终极方案
  → 分析时的提问：「我现在的认知处在第几循环？下一轮实践要检验什么假设？」
- **感性认识到理性认识的飞跃**：实践产生感觉、印象等感性认识；积累足够材料后经过去粗取精、去伪存真、由此及彼、由表及里的改造制作，飞跃为概念与规律性的理性认识
  → 分析时的提问：「我手上的原始材料够多够真吗？我对它做过『十六字』加工，还是停留在印象层面就下了结论？」
- **实践是检验真理的唯一标准**：理论是否正确，不依主观感觉而定，而依社会实践的结果而定；判定认识之是否真理，只能靠实践
  → 分析时的提问：「我这个判断打算用什么可观察的实践结果来验收？验收标准和时间点写清楚了吗？」
- **直接经验与间接经验**：一切真知最终发源于直接经验；但人不能事事直接经验，多数知识是间接经验——而间接经验在源头处仍是前人与他人的直接经验，故须以我之实践加以消化验证
  → 分析时的提问：「这个结论是我亲验的，还是转手的？转手了几道？我该用哪个小实验亲自验证关键一环？」
- **知行合一**：认识的能动作用须表现为从理性认识到实践的第二次飞跃——拿规律性的认识去能动地改造世界；知而不行，只是未知
  → 分析时的提问：「这个『知道』改变了我的哪个动作？如果行为没变，我是真的知道了吗？」
- **没有调查就没有发言权（毛泽东，补充）**：你对某个问题没有调查，就停止你对某个问题的发言权；一切结论产生于调查情况的末尾，而不是在它的先头
  → 分析时的提问：「我这个观点背后是调查还是想象？发言权我挣到了吗？」
- **反对教条主义与经验主义（补充）**：教条主义抱住本本拒绝对具体实践做具体分析，经验主义拘守局部经验误把一时一地当普遍真理——两者都以主观与客观相分裂为特征
  → 分析时的提问：「我现在是拿书本/惯例压事实（教条），还是拿个案当规律（经验主义）？」

**典型适用场景**：
- 把分析结论落成行动计划与验证方案（行动闭环全流程）
- 新产品/新业务的最小验证（MVP本质即实践论循环）
- 复盘与认知升级、团队学习机制建设（十六字加工+循环）
- 辨别「假懂」：说得头头是道、从未验证（实践检验标准）
- 对抗纸上谈兵（教条主义）与经验固化（经验主义）
- 进入陌生领域前的调研设计（没有调查就没有发言权）

**常见误用**：
- 只实践不认识：蛮干，用战术勤奋掩盖战略懒惰（缺少从感性到理性的加工环节，实践再多也不长进）。
- 只认识不实践：分析瘫痪，追求「想清楚再动手」而永远没有动手（很多认知只能在实践中获得）。
- 把一次实践结果当终局判决：单次结果受偶然因素影响，需多次循环修正，一次失败不等于方向错。
- 忽视「十六字加工」：收集了一堆一线反馈却不做去粗取精的整理，等于没有飞跃。
- 循环不升级：每次复盘都得出相同结论、做相同动作——螺旋没有上升，只是在原地打转。
- 把「实践检验」窄化为只看短期数据（有些认识的检验周期很长，要用阶段性信号代替终局判决，但不可因此取消检验）。

**操作流程**：
1. **从实践出发定课题**：明确当前要解决的具体问题（来自矛盾论锁定的主要矛盾），列出已知与未知，定义「什么叫搞清楚了」。
2. **深入实践采集感性材料**：到一线去、动手去做，获取直接的、足量的感觉与印象材料（数据、访谈、亲验），记录原始状态不加粉饰。
3. **十六字加工实现第一次飞跃**：对材料「去粗取精、去伪存真、由此及彼、由表及里」，形成概念、判断与规律性认识——写出假设：「我认为___，因为___，若对则___。」
4. **设计再实践检验**：为假设设计最小成本的验证动作（实验、试点、MVP、谈判试探），事先写明验收标准、观察指标与时间期限。
5. **执行并检验真理**：落地验证动作，只以实践结果判定假设真伪；对则固化为方法，错则定位错在哪一环（材料？加工？条件变了？）。
6. **修正认识进入下一循环**：把检验结论写回认知，更新假设与打法，明确「下一循环要比这一循环高级在哪」（更深一层规律 or 更大范围适用）。
7. **沉淀与迁移**：将经多循环验证的认识写成可复用的原则/SOP，标注适用边界（防经验主义），并把需他人验证的间接经验列成待亲验清单。

## 三论联动速查（模块6/7/8组合用法）

1. **结构层（资本论）**：价值从哪来、被谁拿走、矛盾在哪个环节积累 → 产出「利益与分配地图」。
2. **定主次（矛盾论）**：在结构暴露出的全部矛盾中锁定主要矛盾、判定主要方面、预判转化 → 产出「主攻方向」。
3. **行动闭环（实践论）**：把主攻方向变成假设→最小验证→验收→修正的循环 → 产出「行动与升级中的真知」。
4. **循环往复**：行动结果改变结构，结构催生新矛盾，新矛盾要求重新定主次——三论不是三步走，而是持续转动的飞轮。

**总纲一句话**：没有结构分析的主次是盲目的（缺资本论），没有主次的行动是分散的（缺矛盾论），没有行动闭环的分析是空转的（缺实践论）。
